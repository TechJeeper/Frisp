Frisp

A noise-cancelling virtual microphone. Choose the mic you want cleaned, then pick Frisp Mic in OBS, Streamyard, or any other app.

Use it

  1. Install the signed virtual cable, then run the Frisp installer so the microphone is named Frisp Mic.
  2. Open Frisp and choose a microphone. Leave Frisp open.
  3. In your meeting or streaming app, select Frisp Mic.

The original microphone stays available, unchanged, for anything that should hear the room as it is.

Install

Downloads are on the GitHub releases page.

macOS. Install BlackHole 2ch, unzip the release, and run install-macos.sh. That names the cable Frisp Mic. Open Frisp.app and allow microphone access.

Windows. Install VB-Audio Virtual Cable, reboot, unzip the release, and run install-windows.ps1 as administrator. That names the cable Frisp Mic. Secure Boot can stay on.

What it does to the sound

Frisp listens to the microphone you picked, mixes it to a single voice channel, and runs the open-source RNNoise model in real time. Fans, room rumble, and keyboard noise drop back. Speech stays. The result is published on Frisp Mic at 48 kHz.

Noise cancellation can be switched off. Frisp still sends the selected microphone to Frisp Mic.
